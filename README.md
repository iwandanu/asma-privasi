# Kebijakan Privasi — ASMA

Halaman kebijakan privasi aplikasi **ASMA (Ayo Studi Matematika)**,
paket `com.pyq.asma` — dipublikasikan untuk Google Play.

- **Halaman publik:** https://iwandanu.github.io/asma-privasi/
- **Berkas:** `index.html` (satu halaman, tanpa dependensi luar)

Ringkas: aplikasi tidak mengumpulkan data apa pun — tidak ada izin internet,
tidak ada iklan, tidak ada akun; catatan latihan hanya tersimpan di perangkat.

Mengubah naskah: sunting `index.html`, lalu `git commit` + `git push` ke `main`.
GitHub Pages membangun ulang otomatis (±1 menit).
